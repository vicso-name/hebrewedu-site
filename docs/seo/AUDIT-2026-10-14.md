The 2026-10-13 eight-article semantic audit explicitly calls this "not confirmed cannibalization" but flags it as the clearest risk — **no post-launch SERP/GSC check exists yet** since the course pages only recently went live.
- **Reading progression**: alphabet guide / Nikud guide (`how-to-read-hebrew-nikud`) / without-vowels article all answer "how to read Hebrew" variants — flagged internally in `keyword-to-url-map.md` as a monitored, not resolved, conflict (0% URL overlap in one pair, but query-text overlap remains).
- **App discovery**: homepage owns *hebrew learning app* / *hebrew alphabet app* / *best app to learn hebrew* — all four map to `/` with mixed Core/Supporting/Explore priority; SERP pilot shows only 1 shared URL (low overlap) across these pairs, so likely distinct SERPs rather than true cannibalization.
- **Vocabulary**: `/blog/how-to-learn-hebrew-vocabulary/` vs `/blog/meet-the-new-verb-directory/` — both touch vocabulary/verb terms; `/blog/meet-the-new-verb-directory/` is also the proposed target for v3's untested *alef bet tutor verb directory* candidate.
