# HebrewEdu Semantic Core v1 — Keyword-to-URL Map

Editorial assignments synthesized from the 136-candidate dataset, qualified coverage, volume records, ten successful Google US mobile Android SERP snapshots, and exact-keyword difficulty results (retrieved 2026-10-10). SERP checks are dated observations; absent listings in returned rows are not treated as proof of no rankings. Volume is Google Ads average monthly search volume, not organic visits.

## Recommended assignments by intent

### Product discovery and app selection

- **Homepage `https://hebrewedu.com/`**: *hebrew alphabet app* (best-supported commercial target; the pilot observed HebrewEdu at position 7 in the 2026-10-10 US mobile Android snapshot), plus *hebrew learning app* as a conditional supporting term. The former has direct GSC wording and a product-match SERP; the latter SERP mixes app pages, roundups, app carousel and discussion, and homepage coverage is partial.
- App-specific feature terms (vocabulary app, reading app, beginner app) are supporting only where actual app features match. App-only experiences cannot be represented as browser functionality.
- **Potential different format:** app comparison/“best app” queries imply selection criteria, comparisons and third-party options. The site has no validated independent comparison page; do not force those terms onto a generic story or create a comparison URL until SERP and editorial substantiation justify it.

### Beginner acquisition and study path

- *is hebrew hard to learn* → `/blog/how-hard-is-hebrew-to-learn/`; direct article fit and GSC wording, but its SERP pilot failed, so the specific Google result format remains unverified.
- *learn hebrew for beginners* → no firm target yet. The homepage represents a beginner app path, not a full beginner course. Its pilot failed; retain as Explore pending a successful SERP check.
- *how to learn hebrew alphabet in a week* → `/blog/learn-hebrew-alphabet-7-days/`; focused existing study-plan format.

### Alphabet reference, recognition and pronunciation

- *learn hebrew alphabet*, *how many letters are in the hebrew alphabet*, *hebrew alphabet letter names*, *hebrew final letters* → `/blog/hebrew-alphabet-complete-guide/`. The guide’s table/reference format fits. The learning query has GSC wording; the SERP showed guides, course pages, books and videos.
- *hebrew alphabet chart* → same guide provisionally. SERP features charts/tables and image results, so validate visual/printable expectations; don’t imply a downloadable chart unless one exists.
- *hebrew alphabet pronunciation* and individual letter sounds → same guide only as provisional targets; the guide’s letter-sound table may not satisfy audio or spoken-word pronunciation intent.
- Handwriting/cursive queries → `/blog/why-hebrew-handwriting-looks-completely-different-from-printed-hebrew.md`; keep distinct from printed-alphabet guide where SERPs support the distinction.

### Reading, Nikud and vowel marks

- *how to read hebrew* → alphabet guide provisionally; pilot results mixed reference pages, step-by-step lessons, practice and video. Compare with the Nikud guide before consolidating canonical targeting. GSC wording exists.
- *how to read hebrew words* → `/blog/how-to-read-hebrew-nikud/` provisionally, but pilot query *how to read hebrew nikud* surfaced substantial without-vowels/community intent. This creates potential overlap with the unpointed-reading article; keep distinct only where the actual question differs.
- *how to read hebrew nikud*, *hebrew vowel chart*, *what is dagesh* → `/blog/how-to-read-hebrew-nikud/`; validate that chart/individual-mark formats are satisfied.
- *does hebrew have vowels*, *hebrew with and without vowels*, *how to read hebrew without vowels* → `/blog/why-hebrew-without-vowels-looks-impossible-until-your-brain-adapts/`. Pilot supports orthographic explainers but includes religious/historical pages; explicitly distinguish spoken vowel sounds from written vowel points and state Modern Hebrew scope.
- **Conflict to monitor:** the alphabet guide, Nikud guide and without-vowels article all address reading progression. Assign based on query modifier and keep internal links explicit; do not use the same broad “how to read Hebrew” target indiscriminately.

### Vocabulary and grammar

- *how to learn hebrew vocabulary* → `/blog/how-to-learn-hebrew-vocabulary/` as a study-method page; pilot SERP also favors word lists, courses and lessons, so this is a partial format match. *hebrew words for beginners* and *most common hebrew words* need a real beginner/frequency list to be a strong target; current method article is insufficient by itself. Do not broaden its promise without adding substantiated list content.
- *hebrew root system* → `/blog/how-the-hebrew-root-system-works.md`; exact topical fit.
- *what are hebrew binyanim* → `/blog/hebrew-binyanim-explained.md`; narrow explanatory fit. *hebrew grammar for beginners* is too broad for this page; no current target recommended.
- *hebrew verb conjugation chart* → validate whether the page actually provides a web-accessible, chart-like directory. A product-update article is not a substitute for a functional resource.

### Browser games and app games

- *hebrew alphabet games online* → `/play/`; SERP formats are browser games, quizzes and interactive activities, so this is a strong format assignment. *hebrew alphabet quiz* → `/play/alef-bet-rush/`; *free hebrew learning games* → `/play/`; other game terms map only to actual playable browser tools.
- Keep app lessons, mobile-only games and browser-playable games separate. Never target “online” browser intent to a store CTA where a web game exists.
- A proposed “Alef Bet Rush vs Hebrew Mahjong” target is not supported as a comparison by the educational game-design article; hold until comparison is genuinely present and SERP-validated.

## Clusters supported by SERP evidence

The October 10 pilot found exact URL intersection in four comparable query pairs: app-discovery pair (1 shared URL, 6 vs 8 returned); alphabet learning/chart (1, 7 vs 8); chart/how-to-read-Hebrew (1, 8 vs 8); and how-to-read-Hebrew/Nikud (1, 8 vs 8). These support tentative shared-result neighborhoods, not automatic page consolidation. Learn-alphabet/how-to-read-Hebrew had 0 shared exact URLs (7 vs 8), supporting distinct intents. Each pair has small sample sizes and low exact overlap.

## Proposed new-format/content opportunities (not approvals to create)

1. A focused app-selection page is a possibility only after commercial SERP refresh and defensible product/comparison claims.
2. A chart/printable asset may be warranted only if the search results and current guide audit show an actual unmet visual utility.
3. A beginner Hebrew vocabulary list or interactive reference may serve list intent better than the existing method article, but first validate demand/format and source accurate vocabulary.
4. Broad beginner grammar needs a genuinely broad beginner curriculum page/resource; a Binyanim explainer cannot absorb it. Validate before proposing a URL.
5. Maintain `/play/` and its actual games for browser intent; no additional game URL based only on word similarity.
